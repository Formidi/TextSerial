# テキスト連番ツール

GitHub Pages にそのまま置ける静的ツールです。

## 使い方

入力欄に以下のように書きます。

```text
テスト[101,4]
```

これは `0101` から始まる 4 桁連番として扱われます。

試行回数を `5` にすると、結果は以下になります。

```text
テスト0101テスト0102テスト0103テスト0104テスト0105
```

## 連番指定の書式

```text
[開始番号,桁数]
```

例:

- `[1,3]` → `001`, `002`, `003` ...
- `[101,4]` → `0101`, `0102`, `0103` ...

## GitHub Pages で公開する方法

1. GitHub で新しいリポジトリを作成
2. `index.html` をアップロード
3. リポジトリの **Settings** → **Pages** を開く
4. **Deploy from a branch** を選択
5. ブランチを `main`、フォルダを `/ (root)` に設定
6. 保存後、公開URLにアクセス

## 補足

- 外部ライブラリは使っていません。
- ブラウザだけで動きます。
- 改行あり・なしの両方に対応しています。
